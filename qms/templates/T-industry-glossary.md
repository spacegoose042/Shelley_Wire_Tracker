# T-glossary — construction quality terms (plain language)

For people coming from manufacturing / EMS. Not a legal glossary.

| Term | What it means here |
| --- | --- |
| **AHJ** | Authority Having Jurisdiction — usually the city/county electrical inspector (in Wichita, MABCD). They can fail your rough-in or final. |
| **As-built** | Drawings marked to show what was actually installed. |
| **ASI** | Architect’s Supplemental Instruction — a change to the documents after bid. |
| **Attic stock** | Spare material turned over to the owner at closeout. |
| **Buyout** | Purchasing the job’s material from the estimate after award. |
| **CBA** | Collective bargaining agreement (IBEW). |
| **Closeout** | Final documents, punchlist, training, warranties, so retainage can be released. |
| **Commissioning (Cx)** | Structured start-up and functional testing, often by a third party. |
| **Cost code** | Bucket in Vista for labor/material types so job cost matches the estimate. |
| **CQC** | Contractor Quality Control — federal-style QC program. |
| **Definable feature of work** | A chunk of the job you can inspect as a unit (e.g. “2nd floor rough-in”). |
| **Division 26** | CSI spec division for electrical. 27 = communications, 28 = electronic safety/security. |
| **EMR** | Experience Modification Rate — workers’ comp modifier used in prequal. |
| **Energize** | Put power on equipment. A hold-point event. |
| **FOD** | Foreign object debris/damage — critical on aviation work. |
| **GC** | General contractor. Often your customer. |
| **Hold point** | Work stops until someone signs the ITP. |
| **ICRA** | Infection Control Risk Assessment — healthcare construction. |
| **IFC** | Issued for Construction — the drawing set you build from. |
| **ITP** | Inspection and Test Plan. |
| **Journeyman / apprentice** | IBEW (and license) classifications. Apprentices work under supervision. |
| **Liquidated damages (LDs)** | Contract daily penalty for late completion. |
| **MABCD** | Metropolitan Area Building and Construction Department — Wichita/Sedgwick licensing and inspections. |
| **Megger** | Insulation resistance tester. Common recorded electrical test. |
| **NECA / NEIS** | Contractor association / National Electrical Installation Standards (workmanship). |
| **NEC / NFPA 70** | National Electrical Code. |
| **NETA** | InterNational Electrical Testing Association — independent testing firms/specs for gear. |
| **NCR** | Nonconformance report. |
| **NTP** | Notice to Proceed. |
| **O&M** | Operation and maintenance manuals. |
| **Panel schedule** | List of breakers and circuits. Must match the install. |
| **Prequal** | Paperwork GCs/owners require before you can bid (insurance, EMR, safety, sometimes a QC manual). |
| **Punchlist** | Remaining defects at the end of the job. |
| **Qualifying master** | Licensed master electrician who qualifies the contractor license. |
| **Retainage** | Percent of billings held until closeout. |
| **RFI** | Request for Information — question to the designer when drawings/specs are unclear. |
| **Rough-in** | In-wall/in-ceiling work before drywall. Major AHJ inspection. |
| **Shop drawing / submittal** | Manufacturer data or drawings sent for approval before buying/installing. |
| **Substantial completion** | Owner can use the space; punchlist remains. Starts warranty in many contracts. |
| **Takeoff** | Counting material and labor from drawings to build the estimate. |
| **Three-phase inspection** | Federal CQC: preparatory, initial, follow-up (not three-phase power). |
| **TRIR** | Total Recordable Incident Rate — safety metric. |
| **Trim / finish** | Devices, covers, fixtures after walls are done. |
| **Vista** | Trimble Viewpoint Vista — Shelley ERP / job cost. |
| **Witness point** | Invite the owner/GC; you may proceed if they skip after notice (per contract). |
| **WO** | Work order / job number in Vista. |
| **Wire Tracker** | Shelley material pull/receipt app — quality traceability record. |
