# Implementation roadmap

**Status:** Recommended path. Assign names and dates after the process map walkthrough.

Electrical contractors usually do **project QC**, not a company-wide QMS. That is the opportunity. Do not try to drop a full EMS-style ISO system on the field on day one.

**Field rule:** If a record takes more than about a minute on a ladder, it will be skipped. Design for a phone tap. Let Wire Tracker capture what it can.

---

## Phase 1 — Baseline (first 30–45 days)

**Outcome:** Leadership agrees how work actually flows, a quality policy is signed, and three to five metrics have a honest baseline.

- [ ] Walk [02-as-is-process-map.md](02-as-is-process-map.md) with two PMs and one general foreman. Revise the map.
- [ ] Name a quality lead with authority (not just a title).
- [ ] Sign POL-001. Post it.
- [ ] Inventory existing documents: safety manual, submittal process, closeout templates, Vista reports, license binder.
- [ ] Baseline: labor vs estimate, inspection first-pass (even if only from memory + AHJ tags this month), rework if identifiable, material stockouts, days to closeout on recent jobs.
- [ ] Confirm MABCD license, qualifying master, insurance, EMR, OSHA 300A, and any Avetta / ISNetworld IDs for the prequal binder.

**Do not** write twenty procedures in this phase.

---

## Phase 2 — Core procedures (60–120 days)

**Outcome:** Six procedures issued. Every new awarded job gets a project quality plan and ITPs.

- [ ] Issue QM-001 (after filling brackets).
- [ ] Issue QP-01 through QP-06.
- [ ] Train PMs on T-PQP. First live job uses it.
- [ ] Build a small ITP library from T-ITP-26 for scopes Shelley repeats (underground, rough-in, gear, lighting, fire alarm, testing).
- [ ] Document control rule: field only works to current drawings.
- [ ] Wire Tracker receiving / pull discipline becomes the official material record (QP-03).
- [ ] Start F-04 NCRs on failed inspections and wrong material — even if the first month is messy.

---

## Phase 3 — Measure and improve (120–270 days)

**Outcome:** Monthly one-page quality review. Audits on live jobs. Estimating gets actuals.

- [ ] Monthly management review using the metrics document.
- [ ] Internal audit: two or three jobs per quarter against the ITP.
- [ ] CAPA (F-05) for repeats — not every NCR needs a five-why, but repeats do.
- [ ] Labor variance by cost code returned to estimating.
- [ ] Optional: vendor scorecard (on-time, defect, submittal match).

---

## Phase 4 — Certify only if it sells work

**Outcome:** Documents already look like ISO 9001. Certification is a choice.

Pursue ISO 9001 only if hospital systems, federal agencies, or aerospace owners start requiring it in prequalification.

A complete company quality manual plus project QC plans already wins many GC/owner prequal packages without a registrar.

If federal work (USACE / NAVFAC) is pursued, use T-3PH (three-phase inspection) on those jobs even if the rest of the company stays on simpler ITPs.

---

## What translates from EMS — and what does not

**Keep:** document control, receiving inspection, traceability, NCR/CAPA, vendor control, internal audit, management review, continuous improvement as a rhythm.

**Drop or translate:**

| EMS habit | Construction equivalent |
| --- | --- |
| PPM / SPC on a repeating build | First-pass inspection rate, rework hours, punchlist density |
| Customer RMA / returns | Punchlist items + warranty callbacks |
| On-time delivery of a lot | Milestone dates + material staged when the crew needs it |
| Your controlled drawing package | Spec + IFC drawings + RFIs/ASIs you do not own |
| Internal QA inspector as gate | Often the AHJ / owner / commissioning agent |
| Cleanroom / ESD as default | Use when the site (aviation, healthcare, data) requires it |

---

## Suggested first live job

Pick a medium commercial or industrial job with a cooperative PM — not the most political hospital or base job. Run T-PQP + two ITPs (rough-in and gear, or rough-in and lighting). Debrief in writing. Then scale.
